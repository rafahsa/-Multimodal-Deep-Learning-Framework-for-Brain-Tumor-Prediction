Experimental Setup

BraTS 2018 — 5-Fold Stratified Cross-Validation

285 patients (210 HGG, 75 LGG) with 2.8:1 class imbalance ratio. Patient-level splitting ensures no data leakage across folds. Framework prioritizes probability reliability, operating point controllability, and balanced error behavior.

DATASET

BraTS 2018

285 patients with multimodal MRI: T1, T1ce, T2, FLAIR (4-channel early fusion). Binary labels: HGG vs LGG.

Preprocessing Pipeline

Four-Stage Transformation from Raw MRI to Training-Ready Tensors

Disk-based preprocessing pipeline using SimpleITK, converting raw NIfTI volumes into standardized 128³ tensors. Runtime augmentation via MONAI applied only during training.

STAGE 01

N4 Bias Correction

Removes scanner-specific intensity inhomogeneity using iterative B-spline fitting with Otsu masking.

iterations: [40,40,30,20]
STAGE 02

Z-Score Normalization

Per-patient voxel-wise standardization on brain voxels only. Background preserved at zero.

(x - μ) / (σ + 1e-8)
STAGE 03

ROI Cropping

Union bounding box across all four modalities with 10-voxel padding, eliminating empty background.

mode: union | pad: 10
STAGE 04

Isotropic Resize

Linear interpolation to fixed grid enabling batched 3D convolutions across the full patient cohort.

128 × 128 × 128

Framework Design Principles

Clinically Robust, Calibration-Aware, Controllable

🔬

Balanced Error Behavior

FN/FP ratio of 1.00 (3.4/3.4) vs. SwinUNETR's imbalanced 1.29 (3.6/2.8). Enables predictable trade-offs via threshold adjustment for clinical deployment.

🧬

Probability Reliability

Platt-calibrated outputs mean P(HGG)=0.80 corresponds to ~80% true HGG rate. ECE reduced 26.9% — clinicians can trust confidence levels, not just binary predictions.

🛡

No Data Leakage Guarantee

Patient-level splits (StratifiedKFold, seed=42), OOF integrity verification (7 automated checks), disjoint calibration/threshold sets, forensic audit passed.

⚖

Complementary Model Behavior

All coefficients positive (no model vetoes). CNN captures textures, Transformer captures global context, MIL identifies critical slices. 67% multi-model errors corrected.

⚡

Operating Point Controllability

Two deployment modes: balanced screening (τ=0.41, F1=0.9365) and high-sensitivity triage (τ=0.38, Recall=0.9524). Configurable at inference time.

📊

Statistical Rigor

1000-iteration bootstrap CIs, paired t-tests, nested CV for meta-learner evaluation, and forensic leakage tests with shuffled-label XGBoost baseline.

Ablation Studies

Design Decisions Validated by Controlled Experiments

Table 4: Entropy vs. Random Slice Selection (MIL)

Entropy-based selection (top-k slices with highest Shannon entropy) vs. random selection for DualStreamMIL-3D. Entropy: AUC 0.7990 ± 0.0909, F1 0.8822 ± 0.0132, FN 1.8. Random: AUC 0.7310 ± 0.0500, F1 0.8485 ± 0.0200, FN 3.2.

+9.3% Relative AUC gain (0.7990 vs 0.7310) • FN reduced 44% (1.8 vs 3.2)

Table 5: Basic vs. Enhanced Meta-Learner (Nested CV)

Enhanced meta-learner adds probability statistics (mean, std, min, max, range), inter-model margins, entropy, argmax indicators. Result: FN reduced (2.8 vs 3.4) but FP doubled (7.8 vs 3.4). Recall: 0.933 vs 0.919, but F1: 0.881 vs 0.920.
