Processing Pipeline

From Raw MRI to Clinical Prediction

A rigorous 4-stage preprocessing pipeline transforms raw NIfTI volumes into standardized 128³ tensors ready for deep learning.

01
✦

N4 Bias Correction

Removes intensity non-uniformity artifacts inherent to MRI acquisition using SimpleITK's N4ITK algorithm.

02
≡

Z-Score Normalization

Standardizes voxel intensities to zero mean, unit variance per volume — essential for stable gradient-based training.

03
⧉

ROI Cropping

Extracts the brain region of interest, removing empty background voxels to focus computation on clinically relevant tissue.

04
▣

Isotropic Resize

Resamples all volumes to a uniform 128 × 128 × 128 grid, enabling batched 3D convolutions across patients.

Model Architecture

Three Complementary Learning Paradigms

Each base learner captures distinct spatial and contextual patterns, combined via out-of-fold stacking with logistic regression meta-learning.

3D CNN

ResNet50-3D

Deep residual network operating on full 3D volumes. Pretrained with MedicalNet weights for robust low-level feature extraction from multimodal MRI.

50 Layers Deep
Transformer

SwinUNETR

Shifted-window vision transformer encoder from MONAI. Captures long-range spatial dependencies that CNNs miss via hierarchical self-attention.

128³ Input Resolution
MIL

DualStream MIL

Multiple instance learning on entropy-selected 2D slices. Dual attention + critical-instance streams identify the most diagnostically informative regions.

16 Top-k Slices

Capabilities

Built for Reproducibility & Clinical Translation

🔬

Grad-CAM 3D Interpretability

Volumetric gradient-weighted activation maps reveal which brain regions drive each classification decision.

⚖

Platt Calibration

Post-hoc probability calibration ensures predicted confidences align with true diagnostic frequencies.

🧬

Entropy-Based Slice Selection

Information-theoretic ranking surfaces the most diagnostically rich axial slices for the MIL pathway.

⚡

MONAI-Powered Augmentation

3D spatial transforms — random affine, elastic deformation, intensity shifts — with medical imaging best practices.

🔄

Out-of-Fold Stacking

Patient-level stratified k-fold ensures no data leakage while generating diverse meta-learner training signals.

🎯

Tunable Clinical Thresholds

Sensitivity–specificity trade-off controllable at inference time for different clinical screening scenarios.
